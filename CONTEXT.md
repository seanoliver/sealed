# Sealed

The shared language for an owner collecting and maintaining private contact information through an address book.

## Language

**Sealed**:
The product. Sealed is the brand; it contains an owner’s address book but is not itself synonymous with that collection.
_Avoid_: Address Book as the product name

**Address book**:
The owner’s single private collection of contacts. It has no independent title or name; user-facing attribution comes from the owner name.
_Avoid_: Book title, named book, contact list

**Owner name**:
The human-readable name of the person who owns the address book. A first name is sufficient; this is distinct from both the address book’s link and the owner’s email alias.
_Avoid_: Account name, book title, email alias

**Invite page**:
The public, write-only page an owner shares so another person can submit contact information to the address book.
_Avoid_: Ask-your-friends page, public address book

**Optional invite field**:
A recipient detail that an owner deliberately enables for the invite page. Partner name, kids’ names, and birthday are optional invite fields and default to disabled for a new address book.
_Avoid_: Required field, custom field
