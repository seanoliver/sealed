# Sealed

The shared language for an owner collecting and maintaining private contact information through an address book.

## Language

**Sealed**:
The product. Sealed is the brand; it contains an owner’s address book but is not itself synonymous with that collection.
_Avoid_: Address Book as the product name

**Address book**:
The owner’s single private collection of contacts. It has no independent title or name; user-facing attribution comes from the owner name.
_Avoid_: Book title, named book, contact list

**Owner name**:
The human-readable name of the person who owns the address book. A first name is sufficient; this is distinct from both the address book’s link and the owner’s email alias.
_Avoid_: Account name, book title, email alias

**Invite page**:
The public, write-only page an owner shares so another person can submit contact information to the address book.
_Avoid_: Ask-your-friends page, public address book

**Waitlist**:
The list of emails that requested access to the private beta, each with a pending or approved status. Requesting access through the entry form or Google adds an email as pending; approving it lets that email create an account. Approved emails stay on the list.
_Avoid_: Signup list, queue

**Beta invitation**:
The approval, and the email announcing it, that lets a waitlisted person create an account. It is unrelated to the invite page.
_Avoid_: Invite (reserved for the invite page)

**Optional invite field**:
A recipient detail that an owner deliberately enables for the invite page. Partner name, kids’ names, and birthday are optional invite fields and default to disabled for a new address book.
_Avoid_: Required field, custom field

**Household builder**:
The invite-page section where a recipient enters their own first and last name, then optionally adds a partner and up to 10 kids. Each added person has a first name and a last name that defaults to the recipient's.
_Avoid_: Family form, name fields

**Sender country**:
The country an owner mails from, set as "I mail from" in Settings and stored as a two-letter code (default US). Envelopes to that country leave off the country line.
_Avoid_: Home country, owner country

**Envelope**:
An address as it prints: the household line and address lines in the order the recipient's country uses, with the country name in capitals last unless it is the sender country.
_Avoid_: Address label, mailing block
